# GJPLab Android Feature Lab

GJPLab is a small Kotlin app for learning current Android fundamentals by reading, running, and extending contained working features. It uses Jetpack Compose and Material 3, Activity navigation with explicit `Intent`s, Koin dependency injection, Firebase service demonstrations, and a project-local Android agent-skill library.

Start with the [documentation index](doc/README.md) for architecture, visual-system, splash, Firebase, and agent-skill guidance.
